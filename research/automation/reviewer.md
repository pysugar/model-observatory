## 给独立复核者

读取 PR 的当前 head、变更摘要、所引来源和预览。做轻量事实复核，不要求审计级证明，也不要求重新运行付费模型实验。重点发现：

- 明显的模型名称、版本或别名错误；已退役/受限模型被写成普遍可用。
- token 单价、币种、百万/千单位、输入/输出、缓存及整套任务费用混淆；已结束优惠或明显过时价格。
- 不同基准、推理档位、回退配置或样本条件被写成直接胜负；估计值或社区感受没有标注。
- 页面、筛选、预算边界、CSV 导出或数据缺失的明显问题。

结果写“可接受 / 需修改”，指出具体文件或页面位置、理由及必要链接。记录评审的完整 head SHA。若只是估算或社区反馈而标注清楚，不要自动要求删除。未复核的部分直说，不把 CI 通过视为事实正确。

复核者与研究者应是不同执行主体。独立 Agent 的文字报告有参考价值，但在 GitHub 身份映射尚未配置时，不作为自动合并授权；由用户确认。未来绑定的 GitHub reviewer 必须在当前 head 上给出有效 APPROVED review，不能是作者，也不能用过期或撤销的批准。
